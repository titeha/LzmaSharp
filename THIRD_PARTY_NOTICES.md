# Third-Party Notices

Этот файл перечисляет сторонние компоненты, которые могут присутствовать в репозитории (обычно в `vendor/`).
Их лицензии/условия распространяются на соответствующие файлы.

## LZMA SDK
- Расположение: `vendor/lzma-sdk/`
- Лицензия/условия: Public Domain (как указано в составе SDK)
- Примечание: хранится как upstream reference/эталон.

## 7-Zip (опционально)
- Расположение: `vendor/7zip/`
- Лицензия/условия: см. файлы лицензии внутри исходников 7-Zip (может быть смесь лицензий по частям проекта).
- Примечание: хранится как reference для сравнения/анализа; не является частью сборки `LzmaCore`, если явно не подключено.

## SharpZipLib

- Расположение: пакет NuGet `SharpZipLib`
- Назначение: **только тесты** — эталон для round-trip сверки собственного BZip2-декодера.
- Лицензия/условия: MIT
- Примечание: из production-сборки `Lzma.Core` убран (BZip2 декодируется собственной реализацией). Остаётся лишь как проверочный оракул в тест-проекте.

## SharpCompress (удалён)

- Ранее использовался для декодирования `PPMd` и `Deflate64`.
- Полностью удалён из проекта после появления собственных декодеров (`Ppmd7Decoder`, `DeflateDecoder`). Внешних codec-зависимостей у production-сборки больше нет.
