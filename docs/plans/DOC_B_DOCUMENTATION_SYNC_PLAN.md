## 3. Шаг DOC-B1 — `docs/SDL.md` (DOC-001, Critical)

Цель: убрать заявление об атомарности извлечения сверх доказанного;
добавить практику staged-создания.

Allowlist: только `docs/SDL.md`.

Предварительный read-only просмотр (до правки):

1. Есть ли в `tests/` блокирующие тесты extract-rollback (поиск по
   `File.Delete`/rollback/откат в тестовых файлах). От результата зависит
   формулировка: «targeted regression tests существуют» писать только при
   их наличии; иначе — «механизм реализован в ядре, целевые регрессионные
   тесты отсутствуют/неполные».
2. Точные гарантии кода: `overwrite:false` на всех extract-API сервиса
   (конфликт имён → отказ, существующие файлы не перезаписываются);
   откат удаляет только созданное операцией; каталоги создаются лениво и
   тоже учитываются в откате.

Правки:

1. §2, пункт об извлечении: статус `[действует]` → `[частично]`, текст:

   > Частичный откат при извлечении. При сбое декодирования файлы и каталоги,
   > созданные операцией, удаляются (`ZipExtractor`, `SevenZipArchiveDecoder`);
   > существующие файлы не затрагиваются (`overwrite:false` — конфликт имён
   > даёт отказ). Полная транзакционность извлечения (журнал операций,
   > отмена, backup конфликтных целей) не реализована — скоуп SEC-001
   > (`docs/plans/SECURITY_REMEDIATION_PLAN.md`).

2. §2, новый пункт (после практик создания/извлечения), статус `[действует]`:

   > Staged-создание архива. Запись архива в путь (одиночный 7z, ZIP,
   > multi-volume, запись готового архива из памяти) идёт во временный
   > файл/тома рядом с назначением; публикация — переносом только после
   > успешного завершения. При неудаче, отказе валидации или отмене
   > существующее назначение не затрагивается, временные файлы удаляются.
   > SEC-002 закрыт 2026-08-12 (HEAD `10377e2`), блокирующие регрессионные
   > тесты существуют. Known limitations: multi-volume публикуется
   > несколькими переносами (частичная публикация при сбое посреди коммита
   > не откатывается); см. `SECURITY_REMEDIATION_PLAN.md` §4.5.

3. §5 known limitations — при необходимости дополнить пунктом про SEC-001
   (извлечение): «частичный откат, полная транзакционность не реализована».

4. §3 «более 1500 тестов» — не трогать.

Верификация (AGENTS.md §8, docs-only): `git status --short`,
`git diff --check`, `git diff --name-only`; если добавлены ссылки —
проверить существование целевых файлов и перечислить их.

Критерий приёмки: SDL не заявляет больше, чем доказано кодом и тестами.

Критик: промпт `C:\Temp\DOC-B1_critic_prompt.md` (контракт §9 + факты +
